# 案例：一次校样阶段的校稿（合成案例）

本技能里每条铁律的**实证来源**。案例是**合成的**——把多次真实校稿中反复出现的
失效模式组装成一个连贯的教学场景，稿件、期刊、数值均为示意，
**不对应任何一篇真实投稿**。数字看一眼量级即可，不要当作基准值。

---

## 任务

- 文件：`paper.tex`，约 1700 行，CRLF，UTF-8 无 BOM
- 期刊：Elsevier 系某工程期刊，处于**校样（proof）阶段**
- 可用素材：`proof.pdf`（出版社排好的定稿校样，约 20 页，**无文字层**）
- 约束：**无法编译**——缺出版社专有文档类、宏包与全部图片资源

**产出**：分四轮累计应用约 90 处修改，全部经 `grep` 回查核实。

| 轮次 | 内容 | 处数（示意） |
|---|---|---|
| 一 | A 类硬错误 + B 类润色 + 参考文献 | 约 55 |
| 二 | 回修 1 处（highlight 越字符上限）+ 新增若干 | 约 17 |
| 三 | 回修 3 处（`\eqref` 误判）+ 新增 | 约 13 |
| 四 | 清除**我自己引入**的 em dash | 2 |

---

## RED 阶段：无技能的基线测试

**方法**：把原文（未改动的备份）复制到独立目录，交给一个**没有本技能**的 agent，
给出和真实场景里**同样的朴素请求**（"检查一下行文问题…请直接修改这个文件"）。

**结果：报出 6 处，其中 2 处与我本人在正式任务中犯的错一模一样。**

| # | 基线 agent 的行为 | 判定 |
|---|---|---|
| 1 | 在 `\eqref{}` 前补 "equation" | ❌ **同一个错误**。它还给了自信的理由："上文刚定义 the observation equation，此处漏掉名词 equation，句子不成立" |
| 2 | 给一个用连字符代替破折号的句子加上 `---` em dash | ❌ **同一个错误**。原文全文 em dash 计数为 0 |
| 3 | 把 `deviates from its nominal range` 改成 `deviate from their nominal range` | ⚠️ **改一半**：动词和物主代词改了，主语 `the mean deviation` 仍是单数，依然不一致 |
| 4 | 全局重命名 11 处拼错的标签名 | ⚠️ 这是我评估后**明确建议不动**的（出版社可能已写入 XML ID，有断链风险） |
| 5 | 一处时态不一致的修正 | ✅ 合理 |
| 6 | `a effect` → `an effect` | ✅ **真实错误，而我多轮、多个 agent、多次通读全都漏掉了** |

**它没有做的事**：备份、原子化写入、行号回查、参考文献核对（DOI/作者名/年份）、
数字系统性复算、格式合规检查、硬错误与润色建议的分级。

**召回率**：约 4 / 50 —— 对照我最终应用的约 90 处修改中的独立问题数，
也就是**单遍通读只能找到约一成**。

**这一轮测试的价值**：证明了「在 `\eqref` 前加 Equation」和「随手引入 em dash」
**不是某个 agent 的个人毛病，而是系统性失效模式**。所以它们被写成了铁律 1 和铁律 2。

---

## GREEN 阶段：带技能重跑同一场景

**方法**：同样的原文、同样的朴素请求，但让 agent **先读本技能**再执行（要求只出报告、不改文件）。

**结果：技能拦下了一个假 ERROR、改变了两个改法、并挖出一条所有人都漏掉的错。**

### 1. 铁律 1 拦住了一个假 ERROR

细读 agent **主动报了一条 ERROR**，说某句 `in the observation \eqref{...}` 缺名词、句子不成立，
并给出改法"加 `equation`"——**和基线 agent、以及我第一轮的判断完全一样，理由也写得同样自信**。

技能要求先渲染校验。agent 渲染校样对应页，图上写的是
`in the observation Eq. (N) can be expressed as` —— **宏自带 "Eq."，这条是误报，被丢弃。**

> 同一个失败模式，在 RED 阶段（无技能）被采纳并写进了报告；在 GREEN 阶段（有技能）被拦下。

### 2. 铁律 1 反过来挖出一条真错——而且是此前几轮都没人看见的

源码：`based on the sum of squared errors (\eqref{Objective_Function}), where`

源码里只有**一层**括号，看起来完全正常。渲染出来却是：

> ...based on the sum of squared errors **(Eq. (12))**, where

**双层括号。** 因为 `\eqref` 自己带括号。这一处在源码里绝对看不出来。

**这条错在 RED 阶段、以及此前几轮修改中，从未被任何人发现。** 只有渲染才暴露。

```bash
python scripts/render.py proof.pdf --page 6 --dpi 450 --crop 250,2520,1700,230
```

### 3. 铁律 2 改变的不是判断，是改法

"连字符当破折号"被正确判为 ERROR，agent 原本提议改成 `--` 或 `---`。
技能要求**先数**：`scan.py` 报全文 **em dash = 0**。于是 agent
**保留了"这是错的"这个判断，但换掉了改法**——改用逗号或括号。

> 判对了问题，却选错了修法——正是我本人在真实任务里犯的第三类错误。技能在这里把它挡住了。

### 4. 铁律 6 阻止了对出版社标识符的改动

正文标签里有一个拼错的词，出现十几次，是个很显眼的"拼写错误"。
基线 agent 直接全局重命名了 11 处；GREEN agent 按技能把它归入 F 类「仅提示、不建议改」。

### 5. P3 的 grep 回查砍掉了一条伪造引用

三路细读共报约 70 条候选，P3 逐条 grep 回原文：**绝大多数通过、1 条丢弃**。
丢弃的那条把两个不相邻的句子拼成了一段，grep 一查就露馅——它引用的两个片段
在原文里中间还隔着别的内容。

### 对比

| 指标 | RED（无技能） | GREEN（有技能） |
|---|---|---|
| 报告结构 | 6 处混在一起 | A/B/C/D/E/F 六节分级 |

## 我犯的三个错

三个错误是同一类：**我假设了工具的行为而没有验证。**

### 错误 1：假设 `\eqref` 只输出编号

**当时**：读到 `in the observation \eqref{Some_Label}`，
判断"observation 后面缺中心名词，式子编号无处附着"，改成 `in the observation equation \eqref{...}`。
另外两处同理，在 `\eqref` 前加了 "Equation"。

**真相**：该模板的 `\eqref` 输出的是 **`Eq. (N)`**。改后渲染成
**"the observation equation Eq. (7)"** 和 **"Equation Eq. (12)"** —— 语义重复。

**怎么发现的**：做参考文献作者名核对时顺手把校样 PDF 渲染出来看，
在正文里看到了 `...in the observation **Eq. (7)** can be expressed as`。

**修复**：第三轮回退这 3 处。

```bash
# 可复现的验证
python scripts/render.py proof.pdf --page 4 --dpi 400 --crop 1750,2550,1550,900
```

### 错误 2：语言修正撞上格式约束

**当时**：有一条 highlight，我按语法补了个冠词，措辞是通顺了，
**字符数却从 83 涨到 88**。

**真相**：Elsevier 规定 highlight **每条最多 85 字符（含空格）**。
改对了语法，越过了格式上限。

**修复**：下一轮回退为不超过上限的版本（去掉冠词，改用更短的措辞）。

**教训**：语言修正和格式约束要**同时**验证。改完立刻重跑 `compliance.py`。

### 错误 3：改动打破文档自身的风格基线

**当时**：原文某个插入语用**连字符**代替破折号（`conditions-characterized by ... data-remains`）。
我判断需要插入语破折号，改成 `---`。另一处同样。

**真相**：**原文全文 em dash 计数为 0。** 我加进去 3 个。
单独看每个破折号都是"语法正确"的，但相对文章自身的基线就突兀了。

**修复**：第四轮改为括号与 `such as` 结构，`---` 归零。

**附带发现**：其中一处我上一轮只改了尾部，留下了
**逗号开头、破折号收尾的不对称结构**——成对使用的破折号必须两头都是破折号。
这是"改一半"的又一个实例。

## 有效的手段（实测）

| 手段 | 实测效果 |
|---|---|
| **原子化替换**（断言出现次数 → 全通过才写盘） | 拦下过 **2 次**真实错配：一处计数不符（实为 3 处而非预估 2 处）、一处 old string 我抄错了。两次都在写盘前中止，文件完好 |
| **多路并行 + 自己通读，取并集** | 三路分区细读 + 一遍全读，比任何单路都多 |
| **逐条 grep 回查** | P3 闸门，砍掉了若干条行号或引用不准的候选 |
| **渲染 PDF 验证** | 发现 `\eqref` 真相；确认表格里的 `\_` 会渲染成基线以下的孤立下划线 |
| **CrossRef API 核对** | 全部核完：绝大多数有 DOI，**0 条指向错误文献**；查出若干条 bib 年份与卷期矛盾 |
| **结构不变性回归** | 改后行数、花括号平衡、`\begin`/`\end` 配对数、标签与引用计数 —— 与改前完全一致 |
